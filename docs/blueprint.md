# **App Name**: Incident Insight

## Core Features:

- Incident Summary Generation: Generates a brief summary of notable changes of all incident categories on a weekly or monthly basis using an AI tool.
- Incident List Display: Display incidents in a table with columns for reference, status, location, time, type, and severity.
- Search and Filter: Allows users to search incidents by reference number and filter by status, country, severity, and type.
- Status Indicators: Use clear visual indicators for incident status (e.g., 'New', 'In Progress', 'Resolved').
- Severity Levels: Indicate incident severity with different colored icons for emergency, high, medium, and low.
- Key Metrics Display: Shows key metrics such as average response time, resolution time, total incidents, and overall incident rate.
- Download Report: Ability to download a report with the displayed incident data.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) for a sense of trust and stability, reminiscent of corporate dashboards.
- Background color: Light gray (#F0F4F8), to create a clean, modern backdrop that reduces visual fatigue.
- Accent color: Soft violet (#8252FF) for highlights and interactive elements to draw user attention without overwhelming the interface.
- Body and headline font: 'Inter', a sans-serif font providing a modern, clean, and readable experience suitable for data-heavy interfaces.
- Use consistent and simple icons to represent incident types and severity levels.
- Employs a clean, tabular layout for incident data with clear visual hierarchy.
- Subtle transitions for filter selections and status updates, providing a smooth user experience.
